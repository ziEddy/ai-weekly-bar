# AI Weekly Bar

Codex·Claude·Gemini Antigravity의 잔여 한도와 Mac 시스템 상태를 메뉴바 한 칸에서 확인하는 macOS 앱입니다.

**1.3.1 무료 베타를 공개합니다.** [앱 다운로드와 설치 안내](https://github.com/ziEddy/ai-weekly-bar/releases/tag/v1.3.1-beta.1)

## 주요 기능

- **AI 사용량:** Codex / Claude / Antigravity 탭, 잔여 한도, 초기화까지 남은 시간과 날짜, 계정이 제공하는 모델·그룹별 한도.
- **작업 바로가기:** Codex와 Claude의 고정 작업 / 프로젝트 / 최근 목록. Codex의 ChatGPT 고정 대화는 웹에서 열립니다. Claude 목록은 데스크톱 Code / Cowork 로컬 작업이며 웹 Projects와는 다릅니다.
- **시스템:** CPU 사용률과 최근 그래프, 메모리 사용량·압력, 저장 공간, 배터리 상태, 현재 기본 연결의 업로드·다운로드 속도.
- **연결 이름:** Wi-Fi SSID 또는 Ethernet/VPN 서비스 이름. Wi-Fi 이름은 macOS 위치 권한을 허용한 경우에 표시합니다. 위치 좌표를 수집하지 않습니다.
- **자동 갱신:** AI 사용량은 서비스별로 10분마다 조회합니다. 시스템 수치는 시스템 화면을 열었을 때만 2초마다 읽고, 저장 공간은 30초마다 확인합니다.

상단의 **AI 사용량 / 시스템**으로 화면을 전환합니다. 마지막 선택을 기억하며, 첫 실행에는 시스템 탭을 표시합니다. 메뉴바의 잔여 사용량 표시는 계속 유지합니다. 시스템 화면에서 **활성 상태 보기**를 열 수 있습니다.

CPU와 네트워크는 첫 두 샘플의 차이로 계산하므로 시스템 화면을 연 뒤 약 2초 동안 측정 중으로 표시됩니다. 배터리 최대 용량은 추정값이며, 지원하지 않는 센서 항목은 제공 안 됨으로 표시합니다. VPN이 기본 연결이면 해당 인터페이스의 트래픽을 표시합니다.

이곳은 소개·설치 안내와 실행 앱을 제공하는 배포용 저장소입니다. 앱 소스는 포함하지 않습니다. `Code → Download ZIP`이나 Release의 자동 생성 `Source code` 파일은 실행 앱이 아닙니다. Release의 앱 이름이 적힌 ZIP을 받으세요. GitHub Star·좋아요·댓글·팔로우는 다운로드 조건이 아닙니다.

## 필요한 환경과 베타 상태

- macOS 13 이상, Apple Silicon 또는 Intel 맥용 Universal 실행 파일.
- 시스템 탭은 구독 로그인 없이 사용할 수 있습니다.
- AI 사용량은 각 공식 클라이언트에 본인 구독 계정으로 로그인해야 합니다. API 종량제 크레딧 잔액을 표시하는 앱은 아닙니다.
- Antigravity 사용량 조회에는 로그인한 공식 Antigravity 앱이 실행 중이어야 합니다.
- Apple Silicon에서 빌드와 자체 검사를 확인했습니다. Intel·구버전 macOS 실기기 검증은 완료하지 않았습니다.

**Developer ID 서명·Apple 공증이 없는 무료 베타**입니다. 첫 실행 시 개발자 확인 관련 경고가 나올 수 있습니다.

## 실험적 연동과 확인 상태

Claude 연동은 설치된 공식 CLI의 실험적 내부 인터페이스를 사용합니다. 개발자의 Commercial Terms 동의 여부는 확인되지 않았으며, Anthropic 문의는 초안만 작성한 미발송 상태입니다. 이 구현에 대한 공식 허용 답변을 받은 앱이 아닙니다. Antigravity는 실행 중인 공식 앱의 로컬 서버에서 사용량을 읽습니다. 공식 클라이언트와 로컬 메타데이터 형식이 바뀌면 연동이 중단되거나 업데이트가 필요할 수 있습니다.

[Anthropic 공식 안내](https://code.claude.com/docs/en/legal-and-compliance)는 제품에서 Claude Code를 실행할 때의 Commercial Terms 등 조건을 설명합니다. 공개 배포는 해당 조건을 충족했다는 인증이 아닙니다.

## 개인정보

각 사용자의 공식 클라이언트와 로컬 작업 메타데이터, Mac 시스템 수치를 화면에 표시합니다. 앱에는 개발자 서버로 전송하는 분석·광고·자동 업로드 기능이 없습니다. 모델에게 메시지를 보내지 않으므로 조회와 탭 전환은 모델 토큰을 사용하지 않습니다. 공식 클라이언트의 자체 인증·통신·캐시는 별도로 동작합니다. [데이터 처리 설명](PRIVACY.md)

오류를 알릴 때 비밀번호·인증 토큰·계정 파일을 올리지 마세요. 화면에는 개인 작업 제목과 연결 이름이 나타날 수 있으므로 공유 전에 가려주세요.

OpenAI·Anthropic·Google·GitHub·Meta가 제공하거나 후원하는 공식 앱이 아닙니다. 각 서비스 이용에는 해당 제공자의 조건이 적용됩니다.
